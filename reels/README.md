# Reels

Reels analizados y sus guiones en español. Cada reel tiene su carpeta con dos archivos:

- `analisis.md`: datos del reel original, transcripción, estructura, edición, por qué funciona e investigación con fuentes.
- `guion.md`: el guion en español con la explicación de cada parte, la descripción del post y cómo grabarlo.
- `edicion.md` (algunos reels): instrucciones para que una IA edite el video crudo.
